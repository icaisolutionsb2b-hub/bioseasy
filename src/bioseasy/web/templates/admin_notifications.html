ntfy

Every alert - a backup that finished or failed, a passcode to confirm, a backup that is due or overdue, a storage problem - is published to one ntfy topic. Install the ntfy app on your phone and subscribe to the same topic to receive them.

On the public ntfy.sh server anyone who knows a topic name can read it, so pick a long, unguessable one - or use your own ntfy server with an access token.
